3. 核心发现摘要
================================================================================

HTTP 协议:
  ✓ 方法: POST (不是 GET)
  ✓ Body: JSON (不是 multipart/form-data)
  ✓ URL 查询: output (必需), source_lang/target_lang (可选)
  ✓ Content-Type: application/json

请求格式:
  ✓ 图像: PNG 格式 (完整文件字节, 不是 BMP, 不是原始像素)
  ✓ 编码: Base64 (PNG 文件 → Base64 字符串)
  ✓ 字段: image (必需), label (可选), state (必需)

响应格式:
  ✓ 类型: JSON
  ✓ 字段: image/sound/text/error/auto/press/text_position (所有可选)
  ✓ 至少一个字段必须存在

自动模式:
  ✓ 启动: 用户按热键一次 (mode != 0)
  ✓ 轮询: 通过 "auto" 字段控制 ("auto" 继续, "continue" 跳过)
  ✓ 间隔: ai_service_poll_delay (默认 200ms)
  ✓ 停止: 用户第二次按热键或进入菜单

配置:
  ✓ ai_service_enabled (启用/禁用)
  ✓ ai_service_url (端点 URL)
  ✓ ai_service_mode (0=image, 1=speech, 2=text, 3=combined)
  ✓ ai_service_pause (激活时暂停)
  ✓ ai_service_source_lang (源语言)
  ✓ ai_service_target_lang (目标语言)
  ✓ ai_service_poll_delay (轮询间隔)

版本兼容性:
  ✓ 首次支持: RetroArch 1.7.8
  ✓ 稳定版本: 1.15.0+
  ✓ 当前: master branch
