Open Source BYOK (自带 API Key)

💡 核心理念

告别切屏，同屏陪伴

传统攻略需要频繁切换浏览器，导致体验割裂甚至模拟器闪退。RetroSprite 作为一个独立 Android 悬浮窗应用运行于 RetroArch 之上。

  • ✅ 不侵入核心： 利用 Android 无障碍服务与屏幕采集，无需修改高门槛的 C/C++ 模拟器内核。
  • ✅ BYOK 模式： 用户自带 API Key，接入喜欢的 LLM（如 GPT-4o-mini 或 DeepSeek），开发者零服务器成本。
  • ✅ 极高扩展性： 完美适配目前火爆的 Android 开源掌机（如 Retroid, Odin 等）市场。

⚙️ 系统架构设计

👁️

1. 感知层 (Perception)

如同助手的眼睛，实时获取游戏状态。

  • • MediaProjection API：静默采集屏幕画面流。
  • • 端侧 OCR：使用 Google ML Kit 或 PaddleOCR 识别屏幕关键文本（等级、地图、对话）。
  • • 视觉理解：定期将截图发送至 Vision LLM 判断当前游戏场景。
AI
🧠

2. 大脑层 (Brain)

利用 LLM 的非结构化信息处理能力。

  • • 自定义大模型：支持 OpenAI 格式的 API 接入。
  • • 本地知识库 (RAG)：将百科攻略向量化，匹配当前 OCR 识别到的关键字提取上下文。
  • • 动态 Prompt：“你是一个资深玩家助手，根据画面给出一句关键提示”。
✨

3. 交互层 (Interaction)

优雅且沉浸的用户界面展示。

  • • Kotlin + Compose：构建现代化的 Android 悬浮界面。
  • • 无障碍控制：利用 Accessibility Service 实现顶层覆盖，且无需“绘制悬浮窗”等敏感权限。
  • • UDP 联调：向 RetroArch 发送指令（保存/读取/暂停）。
