# Chrono Trigger / 时空之轮 Source Notes

## Official Sources

- `ct.square_enix` and `ct.square_enix_mobile`: linked-source factual references only.

## Community Sources

- `ct.community_wiki`, `ct.techs_wiki`, and `ct.zh_wiki_title` are used for factual cross-checking and name mapping only.
- Do not copy walkthrough prose, ending lists, script text, or long Tech/boss tables.

## Localized-Name Sources

- `ct.localized_name_audit` records project-reviewed Chinese aliases and ambiguity handling.
- `魔王`, `青蛙`, and `未来` must be interpreted with game and question context.

## Rejected Sources

- ROM script dumps.
- Copied fan-translation scripts.
- Full ending guides.
- Long copied boss strategy pages.

## Reviewer Notes

This Lite pack is deliberately low-spoiler. Complete endings, late boss routes, Black Omen, and version-specific naming tables belong to an expanded pack.
