# Golden Sun / 黄金太阳 Source Notes

## Official Sources

- `gs.official_manual`: linked-source factual reference only. Do not copy manual prose, scans, tables, or page layouts into GKP rows.

## Community Sources

- `gs.community_wiki`, `gs.community_class`, and `gs.zh_wiki_series` are used only to cross-check names, entity relationships, and broad system facts.
- RetroSprite answer text is original, short, and low-spoiler.

## Localized-Name Sources

- `gs.localized_name_audit` records project-reviewed Chinese aliases and ASR-prone variants.
- Terms marked as uncertain in planning docs should remain out of shipped aliases until separately sourced.

## Rejected Sources

- ROM script dumps.
- Full walkthrough text dumps.
- Commercial guidebook excerpts.
- Copied manual scans or OCR text.

## Reviewer Notes

This is a `coverage_tier: lite` first-support package. It intentionally covers common beginner questions and name matching, not a full walkthrough or all Djinn locations.
