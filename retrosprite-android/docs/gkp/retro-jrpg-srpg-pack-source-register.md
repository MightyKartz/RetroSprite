# Retro JRPG/SRPG Pack Source Register

This register is a planning inventory for Phase 1 Chinese GKP Lite authoring.
It does not authorize copying guide prose, ROM scripts, manual scans, or large
tables into GKP data. Final GKP rows must cite specific `source_id` values in
`sources/citations.jsonl` and use original short RetroSprite summaries.

| --- | --- | --- | --- |

### Rejected Or Unsafe Sources

- ROM script dumps.
- Full walkthrough text dumps.
- Copied manual scans or OCR text.
- Commercial guidebook excerpts.
